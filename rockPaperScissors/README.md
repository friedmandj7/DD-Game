# DD-Game

### Rock Paper Scissors

This is a simple code base for a game of 
rock paper scissors that will run in the terminal. 

## To run the game: 
1. Clone this repo into your local machine.
2. Open the repo in VSCode (or IDE of your choice).
3. Run `npm install prompt-sync` in your terminal. Without this the game won't be able to accept player's input. 
4. Run `node Game-1.js` and play!
